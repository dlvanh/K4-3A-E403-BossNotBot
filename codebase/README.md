# codebase/

Prototype Bot Tom Tát — bot Discord tóm tắt thông báo/trò chuyện bằng AI, do Đoàn Anh Quân phụ trách.

**Chạy bằng pip, xem hướng dẫn đầy đủ tại [`HUONG_DAN.md`](./HUONG_DAN.md) (khởi động nhanh: [`KHOI_DONG_NHANH.md`](./KHOI_DONG_NHANH.md)).**

`src/codebase/` là khung dự án tạo bằng `uv` (chưa dùng đến trong bản prototype hiện tại) — file bot chạy thật nằm trực tiếp trong thư mục này (`tom_tat_bot.py`), cài đặt qua `requirements.txt`.
